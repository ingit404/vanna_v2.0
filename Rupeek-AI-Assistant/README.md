*Rupeek-AI-Assistant* is the main folder in the *Category-Team* github repository.
It enables team members to query business datasets in **natural language** and receive accurate SQL + data responses without requiring technical knowledge. 

#Features

-  Natural language query understanding using Generative AI  
-  Converts queries into **SQL** dynamically  
-  Returns query results with structured insights  
-  Allows iterative conversation for follow-up analysis  
-  Easily extendable across new datasets and business areas  
-  Secure access to internal data only
